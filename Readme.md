# Transbot - base móvil para transporte de materiales 

Este repositorio contiene todos los archivos y documentos del proyecto del Transbot.

## Estructura del repositorio

```
transbot  
├──analysis  # estudios, documentos de análisis, evaluación de alternativas, etc.    
├── design  # *domain-specific design*: por ejemplo, diseño CAD mecánico   
├── documentation  # documentación generada   
├── draft  # borradores y notas de trabajo   
├── ide  # configuración de entornos de desarrollo   
├── libs  # dependencias externas y entornos autocontenidos   
├── project  # documentos de proyecto (refinar)   
├── requirements  # ingeniería de requisitos   
├── robotics  # software y herramientas de simulación y control de robots (ROS/Gazebo)   
├── simulation  # modelos y simulaciones dinámicas   
└── systems  # ingeniería de sistemas (MBSE) 
```
