\begin{abstract}
Se describe el proceso de diseño de una base móvil controlada para el transporte de materiales dentro de un taller metalmecánico. Se utilizó ARCADIA como principal metodologíad de MBSE para llevar a cabo el proceso de diseño mecatrónico integral del sistema robótico. Se detalla cada una de las etapas del método ARCADIA y su correspondencia con las metodologías de diseño mecatrónico más conocidas.
\end{abstract}
